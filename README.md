# Персональний помічник

Командний проєкт курсу Python Programming, Neoversity. Консольний застосунок для адресної книги й нотаток із локальним збереженням.

## Запуск після об’єднання модулів

Потрібен Python 3.12 або новіший.

```sh
python3 -m assistant
python3 -m unittest discover -s assistant/tests
```

[Повна інструкція та приклади команд](assistant/README.md) з’являться разом з інтеграційним PR. Пакет можна також встановити у власне віртуальне оточення через `python -m pip install .` і викликати командою `assistant`.
